How to use it in class

  1. Open a device, answer the Predict question on its card, test it with the slider and the model, then press Show the answer.
  2. Put on a Quest 3, open the same page in the Meta Quest Browser and press Enter MR. Hold the real device next to the virtual one.
  3. Link back to the book lesson: stereo → ZED 2i, splats → X5, LiDAR → Pro3, bidirectional data → Lighthouse and ZED.
